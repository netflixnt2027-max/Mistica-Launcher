# Mística Launcher

Launcher Android para dois servidores SA-MP:

- **Terra Mística RP:** 190.102.40.7:7781
- **Nevora RPG:** 143.14.168.211:26558

## Recursos

- Consulta UDP independente para mostrar online/offline e jogadores de cada servidor.
- Botão separado para abrir cada servidor via `samp://IP:PORTA`.
- Conteúdo remoto para GMX, evento e atualizações.
- Painel PHP simples, compatível com hospedagem InfiniteFree.

## Compilação automática

Cada envio para `main` gera o artefato `Mistica-Launcher-APK` no GitHub Actions.

O APK gerado é a versão de testes/debug do launcher.
